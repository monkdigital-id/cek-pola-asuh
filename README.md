# Cek Pola Asuh

Survei refleksi diri singkat (15 pertanyaan) untuk orang tua, untuk mengenali kecenderungan pola asuh: Hangat & Tegas (otoritatif), Tegas & Mengatur (otoriter), Serba Membolehkan (permisif), Pelindung (overprotektif), dan Sibuk & Berjarak (abai).

- Satu file `index.html`, tanpa backend; semua dihitung di browser, tidak ada data yang disimpan atau dikirim.
- Hasil adalah alat refleksi, bukan diagnosis psikologis.

Bagian dari monkdigital.
